# Base de Datos: Plataforma de Renta de Herramientas y Equipos

## 🗄️ Motor de Base de Datos
- **Motor:** PostgreSQL 16
- **Normalización:** Cuarta Forma Normal (4FN)
- **Extensiones:** `uuid-ossp` para llaves primarias universales

## 📁 Archivos Incluidos
1. `schema.sql`: Script DDL con definición de tablas, relaciones, restricciones de integridad referencial e índices.
2. `data.sql`: Script DML para población inicial con usuarios, categorías, proveedores, herramientas y reservas de prueba (mínimo 20 registros por entidad).
3. `diagrama_relacional.png`: Diagrama Entidad-Relación exportado en formato de imagen según los entregables obligatorios.
