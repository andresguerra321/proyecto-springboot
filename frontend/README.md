# Frontend: Plataforma de Renta de Herramientas y Equipos

Estructura modular del frontend por perfiles de usuario según especificación:

## 📁 Estructura de Directorios

- `admin/`: Panel de administración (gestión de usuarios, supervisión global de alquileres, reportes de rentabilidad).
- `provider/`: Panel del proveedor (inventario de herramientas, carga de imágenes, aprobación de reservas y estado de devoluciones).
- `client/`: Portal del cliente (catálogo de herramientas disponibles, selector de fechas, carrito/reserva, pagos en línea e historial).
- `assets/`: Hojas de estilo CSS compartidas, scripts JS reutilizables e imágenes.

El desarrollo detallado del frontend se realizará una vez consolidados los endpoints de la API REST.
